# Contribute

The project is small and the bar is specific. Start with the page that matches
the change you want to make:

| | |
|---|---|
| [Contribution rules](rules.md) | The three kinds of change — specification, reference implementation, documentation — and what each must land with. Generated from `CONTRIBUTING.md`. |
| [Code of Conduct](code-of-conduct.md) | The expected standard for technical collaboration and the private route for sensitive conduct concerns. |
| [Security](security.md) | What the format promises and does not, key custody, how to report a vulnerability. Generated from `SECURITY.md`. |
| [Governance](governance.md) | Who decides today, how the specification changes, versioning. |
| [Proposing a spec change](propose.md) | The shape of a proposal that can be evaluated, including new facets. |

Everything here is licensed under the Apache License 2.0. There is no
contributor licence agreement. Open a focused issue or pull request at
[github.com/openpictureintelligence/opi/issues](https://github.com/openpictureintelligence/opi/issues). The
repository's current visibility and the path to public publication are kept
on the [status page](../status.md); while access is restricted, contributions
are handled by invitation.
