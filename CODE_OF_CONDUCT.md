# Code of Conduct

Open Picture Intelligence is a small technical project and welcomes precise,
good-faith participation.

Participants are expected to:

- be respectful and specific, especially when disagreeing;
- focus criticism on the proposal, implementation, or evidence;
- make room for contributors with different backgrounds and workflows;
- avoid harassment, discrimination, threats, doxxing, and disruptive conduct.

If a concern should not be public, contact the founding maintainer through the
GitHub account linked from the project profile rather than posting sensitive
details in an issue. Public technical feedback belongs in an issue or pull
request, and security reports must follow the repository's
[`SECURITY.md`](https://github.com/openpictureintelligence/opi/blob/main/SECURITY.md).

The maintainer may remove comments, close discussions, or restrict project
access when needed to keep participation safe and constructive. Decisions
will be made in good faith and documented when they affect the project.
