# Open Picture Intelligence — specification

This is the normative text of the `.opi` format, version 0, assembled from
the chapters in the repository's `spec/` directory. **This address —
`/spec/` on `openpictureintelligence.org` — is the permanent reference URL
for the specification** and is the URL a future IANA media-type registration
will cite. No such registration has been made or accepted yet.

Propose changes against the chapter files in `spec/`; `SPEC.md` at the
repository root is generated from them.
